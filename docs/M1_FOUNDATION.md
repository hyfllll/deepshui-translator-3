# M1 基础能力

## 范围

M1 聚焦个人本地阅读所需的数据可靠性，不包含账户、登录、云同步、跨端或 2.0 数据迁移。

## 已完成

- 阅读器当前页书签：可添加、取消并从数据库恢复状态。
- 书签唯一性：同一文档同一页最多保留一个有效书签。
- 批注数据接口：创建、查询、更新、软删除，写入绑定文档 generation。
- 并发保护：批注更新和删除使用 baseRevision 比较并交换，拒绝覆盖较新的修改。
- 后台任务：支持幂等入队、优先级、租约、心跳、checkpoint、取消、重试和终态记录。
- PDF 验证：源码运行与 Windows 解包产物均完成真实 PDF 渲染及书签回读。

## 版本边界

3.0 是独立的新资料库。用户通过引用、复制或拖放添加 PDF；程序没有 2.0 扫描器、导入服务、迁移 IPC 或迁移按钮。

Schema 2 中早期预留的 `import_runs` 与 `import_items` 暂不删除，以免在不提升 schema 版本的情况下改变已经发布的数据库结构；当前运行时代码不会读写它们。

## 下一阶段

M2 在现有批注接口之上实现 PDF 文本选区、高亮图层、批注编辑面板和书签导航列表。

# M2c：保真智能排版

## M2c-1 已交付

- 陈列公式：对本地启发式明确识别的公式渲染原 PDF 区域裁剪，保留上下标、分数线、矩阵和原始字形；裁剪失败时回退到提取文字。
- 嵌入图片：通过 PDF.js operator list 获取图片坐标，过滤图标、装饰线和整页背景后，在本机渲染为图片块并插回阅读流。
- 矢量图页兜底：当整页矢量绘制密集、正文稀少且没有长段落时，直接渲染为一个保真图页，避免图表被拆成散乱刻度和标签。
- 本地资源：视觉资源以受限二进制保存到 3.0 独立 SQLite 数据库，不写入外部目录，不上传网络。
- 来源追溯：公式和图片块保留归一化页面矩形及原文页按钮。
- 缓存升级：提取器版本为 `pdfjs-renderer-v2.2-assets`，排版版本为 `local-fidelity-v2.2`；旧版本缓存进入智能排版时自动重建。
- 公式误判保护：仅有普通等号和数字的图表刻度/坐标说明不会触发公式裁剪；需要多个运算符、强数学符号或数学字体证据。
- AI 隔离：M2b 只读取允许的文字块；图片、表格和公式图像不会进入模型请求。

## 安全与容量边界

- 允许的资源格式仅为 PNG、JPEG、WebP。
- 单资源上限 5 MB，单篇文档资源总量上限 80 MB。
- 单篇文档最多生成 250 个视觉资源，每页最多提取 12 个嵌入图片、20 个明确公式。
- 每个排版 revision 仍在一个数据库事务中发布；失败不会留下半套内容。

## 后续 M2c-2 / M2c-3

- 使用跨栏区域、首行缩进、字体连续性、归一化行距和标点升级段落划分。
- 增加跨栏标题/摘要识别和 XY-cut 阅读顺序。
- 根据图注与绘图操作识别矢量图和表格；当前 M2c-1 主要覆盖嵌入位图。
- 可选增加公式 OCR/LaTeX；默认本地视觉保真不依赖 API Key。

# M2b：可选 AI 结构增强

## 使用方式

1. 先在“设置 → AI 引擎”配置一个已选模型的 API Key。
2. 打开文献并进入“智能排版”。本地排版始终可用，不需要 API Key。
3. 用户主动点击“AI 优化（可选）”。界面会明确显示本次发送范围。
4. 收到建议后先展示预览；可“应用布局”到当前阅读会话，或放弃/撤销。

## 固定隐私边界

- 不自动发起网络请求。
- 不发送 PDF 文件、页面图片、文件路径或本地文献库信息。
- 仅从本地排版缓存读取已有的文本、块编号与来源页码；超长文献按块数和字符数限制输入。
- API Key 仍由既有本地加密配置保存，渲染进程不能读取凭证文件。

## 固定内容边界

- 模型只允许返回 `blockIndex`、`blockType` 和 `emphasis` 三个结构字段。
- 模型返回正文、翻译、摘要、未知块编号、重复块编号或无效类型时，客户端会忽略。
- 原文阅读块始终使用本地提取的 `text_content`；不会合并、拆分、重排、删除或写回正文。
- “应用布局”只在当前阅读会话中生效；在原文与智能排版之间切换时会保持，关闭文献或撤销后才回到本地排版缓存，不会覆盖缓存。

## 智能排版中的翻译

智能排版的正文同样支持划词翻译与可选 AI 解释。选择内容会复用右侧翻译栏；来源页按钮与 AI 建议标签不参与文本选择，避免混入翻译内容。

## 深色主题

深色主题统一使用高对比度的控件、输入、提示和排版色板，避免浅色硬编码导致按钮或提示文字不可读。
